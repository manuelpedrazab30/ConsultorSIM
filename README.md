# Consultor UM

Single-file pixel-art game (`index.html`) to study Economics & Business and Accounting & Financial Reporting by playing as a consultant. Exams: 15 Dec.

- Open `index.html` in a browser, or host it (Netlify Drop / GitHub Pages) and add it to the iPad home screen.
- Progress is stored in the browser (`localStorage` key `consultoru1`).
- Tests: `npm i && npm test` (jsdom).
- Checkpoints: `scripts/checkpoint.sh "message"`.
